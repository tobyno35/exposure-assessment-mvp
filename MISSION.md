# MISSION: Build a Sellable Cybersecurity Service MVP

You are working independently on a bounded project.

BUSINESS GOAL:
Create a demonstrable $150 fixed-scope Vulnerability Exposure
and Remediation Assessment service for small businesses.

Success is a useful, honest customer deliverable,
not a large codebase or complex AI architecture.

BUILD:
1. A Python 3 CLI accepting saved JSON assessment evidence.
2. Approved asset scope validation.
3. Basic exposure findings with severity and evidence references.
4. A professional Markdown report generator.
5. Synthetic sample input and a complete example report.
6. Automated tests using Python's standard library.
7. A README showing exactly how to run the demo.

CREATE BUSINESS MATERIALS:
- OFFER.md: one-page $150 introductory service offer,
  defined scope, exclusions, deliverables and turnaround.
- OUTREACH.md: 3 short natural outreach messages for
  prospective small-business customers.
- DELIVERY.md: customer intake, written authorization,
  review checklist and report handoff.
- PROJECT_STATUS.md: what works, test results,
  limitations and the exact next action toward a first sale.

CONSTRAINTS:
- Work only inside this repository.
- No external scanning, exploitation or target discovery.
- No unsolicited messages or real customer interaction.
- No network requests or package installations.
- No secrets, credentials or real customer data.
- All example findings must be clearly labeled synthetic.
- Do not invent verified vulnerabilities or customer results.
- Use Python standard library whenever practical.
- Do not create extra orchestration frameworks.
- Do not deploy, publish, push or spend money.

EXECUTION:
Implement the smallest complete version.
Run the tests.
Fix any failures.
Generate a sample customer report.
Document what is genuinely finished.
Do not claim tests passed unless they ran successfully.
Stop when the deliverables are complete.

You have an execution budget of approximately one hour.
Prioritize a usable demo and sales materials.
Do not ask questions; make reasonable low-risk decisions.
