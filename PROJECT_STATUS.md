# Project status

The demo is complete. The offline CLI validates saved evidence against an approved list of up to five asset IDs, applies three exposure checks, and produces a Markdown report with severity, evidence IDs, remediation, and coverage. The repository includes fictional input, the generated report, an introductory $150 offer, three outreach drafts, and a customer delivery checklist.

## Verification

`PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v` completed successfully with **7 tests passing**. The tests include an exact comparison of the CLI's text output with the checked-in report, out-of-scope rejection, malformed and missing input, duplicate evidence, and missing-evidence coverage. The sample report was generated by running the CLI on the checked-in synthetic JSON.

## Limitations

An analyst must obtain written authorization, confirm the approved asset list, review source artifacts, and normalize observations. The CLI checks the declared scope and applies fixed severity rules. Findings depend on the quality and coverage of evidence supplied. Live testing, independent vulnerability verification, and remediation are outside the service.
